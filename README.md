# 2048 · 经典数字合并游戏

一个零依赖、单文件的 2048 网页游戏，打开 `index.html` 即可游玩。

## 在线体验

GitHub Pages：https://wwwwggii.github.io/game-2048/

## 玩法

- 方向键 / WASD / 触屏滑动，移动全部方块
- 相同数字相撞合并翻倍，目标是拼出 **2048**
- 棋盘填满且无法合并时游戏结束
- 自动记录最高分（localStorage）

## 技术

- 纯原生 HTML + CSS + JavaScript，无框架、无构建、无外部依赖
- 响应式布局，适配手机与桌面浏览器
- 滑动合并算法 + 可移动性判定 + 胜负判定，全部在单个文件中实现

## 运行

直接用浏览器打开 `index.html`，或用任意静态服务器托管本目录。
